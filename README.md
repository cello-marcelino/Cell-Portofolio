# Christian Marcelino — Portfolio

Personal software engineering portfolio showcasing web development, backend services, relational database workflows, and practical applied AI projects.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **UI & Components:** React 19, Tailwind CSS v4, Lightswind UI
- **Typography:** Space Grotesk, Inter, JetBrains Mono
- **Icons:** Heroicons & Bootstrap Icons (Official SVGs)
- **Animation & Canvas:** HTML5 60 FPS Interactive Grid Canvas, Framer Motion

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Production Build

```bash
npm run build
npm run start
```
